# MTGA 中文维护

macOS + Steam 的《万智牌：竞技场》汉化与中英文牌表导入工具，免费使用。

Windows 用户可查看[其他维护者提供的工具](https://shiqidi.lenitatis.com/mod)。

**[下载更新工具 v3](https://github.com/1996Neil/mtga-chinese-updates/releases/download/mtga-2026.64.50-25919252-r1/MTGA-Chinese-Subscriber-v3.zip) · [版本记录](https://github.com/1996Neil/mtga-chinese-updates/releases) · [反馈问题](https://github.com/1996Neil/mtga-chinese-updates/issues/new)**

当前适配：**2026.64.50 / Steam 25919252 / Apple Silicon**。这是测试版：文件与隔离安装恢复检查通过，本次游戏内显示尚未验收。程序未完成 Apple 公证。

## 安装与更新

1. 下载、解压，双击「安装 MTGA 中文维护.command」。旧 v2/v2.1 用户也先安装 v3，保留相同更新源。
2. 完成 Steam 和游戏内下载，退出 MTGA。
3. 打开桌面「MTGA 订阅更新」：**检查更新 → 预演 → 应用更新**。游戏语言保持 **English**。

以后资源更新直接打开桌面工具，无需重复安装。没有匹配版本或校验失败时会停止；恢复入口用于还原上次更新前的状态。无需 Git、Python 或 Codex。

## 订阅与支持

欢迎右上角 **Star** 支持维护。接收新版邮件：**Watch → Custom → Releases**，并开启 GitHub 邮件通知。Star 不等于邮件订阅，未订阅也可主动检查更新。
