# 赛事名称英文、内容中文

用户反馈当前游戏中的新赛事名称被翻译，违反已确认的偏好。旧规则只保护历史名称清单；新审查中文在新Key上被正常采用，导致名称政策漏覆盖。

本次以明确字段作用执行显示偏好，不依赖清单年代或来源优先级：

- `Events/Event_Title_*`、`Events/Event_Cat_*`、双层 `Events/Events/` 下同类字段，以及 `Formats/Format_Title_*` 取当前官方英文。
- 明确的Desc/Description/Body/Instructions/Tooltip介绍字段不适用名称政策，即使路径带Title。
- 普通导航标题、卡牌、类型及关键词不按赛事名称处理。
- 中文候选和来源历史仍保留；显示偏好不会把中文来源删掉或改成官方英文翻译。
- 名称内的本地化引用在名称上下文使用官方英文递归展开；不修改共享系列/人物字段，因此介绍和其他位置仍能显示中文。缺少官方引用或循环引用会拒绝构建。法术力图标等保留官方引用中的原始标签。

测试覆盖新名称无历史政策、中文来源优先级更高、没有来源、介绍、导航标题和精确候选差分。候选修正工具 `event_names.py` 只读官方底稿和已有客户端候选，写入全新隔离目录，不接触游戏或事务；输入Key集合必须一致，所有非名称字段逐项不变。

本地对当前发布输入的检查：共核对1,464个明确名称字段，恢复28个被翻译的赛事名称，并将33个包含引用的名称按官方英文展开，共61个名称字段变化。其余20,330个非名称字段、介绍、其他语言和表不变，名称之外的引用目标原值不变。其余资源层保持上一签名修订的字节。另一个名称初筛命中的Title字段实际是MWM介绍，继续保留中文，因此初筛29项不作为实际名称修正数量。

本次代码与候选验证不自动表示当前游戏已经修复。当前游戏安装使用签名发布资源；资源发版、通过订阅客户端应用、真实游戏显示需分别记录，不能把候选构建或测试当成实际安装。
