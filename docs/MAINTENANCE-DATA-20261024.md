# 精简维护数据工作范围

用户认可公开精简、可复用的维护数据，并明确线上使用者不需要证据包。

实现目标：

1. 解释并量出本地Registry与网站来源索引的区别。
2. 从现有三个独立审查的V2包导出有效维护记录，保持译文、匹配身份和来源覆盖级别不变。
3. 公开具体来源链接与必要元数据，不包含原始快照、整库、私人路径或游戏候选。
4. 提供确定性导出和验证工具及负例测试，不把公开数据变成绕过原有审查/安装门槛的自动批准。
5. 独立审查后推送合并；不改客户端协议、签名feed、Release或本机游戏。

本地Registry当前文件大小680,407,040字节（约648.9 MiB），包含271,049条卡名记录、902,362条历次决策、267,918条本地化来源记录等；它不是一个只列网站名称的清单。公开导出取当前已审查维护记录，不复制整个Registry或历史。

本次公开1,850项维护记录（1,837项既有审查记录、9项卡库纠错、4项模式介绍补译）：`translations.jsonl`为1,260,580字节，来源索引为259,061字节，清单为2,106字节，合计1,521,747字节，约1.52 MB。942个唯一具体来源地址归于4个网站/分发主机，按来源性质及采用状态区分为967个索引条目。

这些数字不是全游戏卡牌数或全部历史译文数，也不是官方译文数量。最终公开文件大小、条目及来源覆盖分类以 `maintenance-data/2026.64.50/manifest.json` 为准。529项仍未找到可靠中文全文、998项仅有部分/概念依据，公开数据保留这些区别，不将其写成官方全文或人工审定。

验证：179项维护器测试中178项通过，1项真实本地底稿检查按公开开发约定跳过；13项新增测试包含实际公开数据完整性、原准入拒绝简化清单、原文参数丢失、指纹篡改、来源引用、AI披露及Mac/Windows/Linux私人路径负例。独立审查逐条对照原三个包及来源索引，确认投影内容和覆盖分类一致；未执行游戏安装或修改发布索引。
