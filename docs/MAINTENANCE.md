# 维护规则与证据索引

日常操作统一使用 [开发说明](DEVELOPMENT.md)、[来源规范](../tools/chinese-maintainer/SOURCE_LOOKUP.md) 和 [发布说明](../tools/subscriber/NETWORK.md)。本页汇总维护政策、数据范围和可核对的证据；操作不再按日期文档选择不同流程。

## 发布入口

源码、下载、Releases 和监控统一在 `1996Neil/mtga-chinese-updates`。当前下载入口由根目录 `download.json` 指定；监控配置、公开下载验证与安装包 profile 使用相同渠道和公钥，不手工改写已签名的 feed 文件。

正式发布使用 stable 和绑定候选的验收记录。testing 只用于明确的测试发布，不能替代正式验收。资源版本用于匹配游戏和复查证据，不代表还需要维护另一套源码或操作入口。

签名清单、Release 附件、来源快照及固定审查记录保持原字节；文档和可执行流程统一到当前路径。没有新文本或资源变化时，复用已有证明不能被描述为做过新的游戏测试。

## 名称英文、内容中文

- `Events/Event_Title_*`、`Events/Event_Cat_*`、双层 `Events/Events/` 下同类字段，以及 `Formats/Format_Title_*` 使用当前官方英文。
- Desc、Description、Body、Instructions、Tooltip 等介绍字段继续采用已审中文，即使路径中有 Title。普通导航标题、卡名、类型和关键词不按赛事名称处理。
- 名称内本地化引用按当前官方英文递归展开，保留法术力图标等标签。缺少引用或循环引用停止构建；不改写介绍等位置共享的中文引用目标。
- 显示政策不删除中文候选或来源证据。实际逻辑在 `registry.py`，隔离修正工具为 `event_names.py`。

2026-10-24 的精确差分证据：核对 1,464 个名称字段，恢复 28 个中文名称并展开 33 个引用，共 61 个变化；其余 20,330 个非名称字段、其他语言、表及资源层不变。另一个初筛 Title 字段是 MWM 介绍，保留中文。候选验证不代表当时已应用到游戏。
