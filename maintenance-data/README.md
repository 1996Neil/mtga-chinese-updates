# 精简汉化维护数据

这里公开可复用的译文和来源索引，方便查阅、纠错和移植。普通玩家使用汉化更新时不需要下载这个目录或任何证据包。

## 包含什么

每个游戏版本一个目录：

- `translations.jsonl`：每行一项维护记录，保存层、Key/LocId、当前英文、中文、英文/中文哈希、字段用途、牌张/客户端身份、来源引用、来源覆盖分类、是否仍含AI表达及处理方式。
- `sources.json`：去重的来源清单，保存网站/分发地址、具体页面或API链接、来源性质、原站声明的来源，以及本次是否采用该来源。
- `manifest.json`：格式版本、适用游戏版本、文件哈希/大小、数量和输入审查包指纹。

网站名称用于知道去哪里查；具体页面链接用于确认查的是哪张牌、哪个版次或哪条介绍。不会把所有内容笼统标为“来自大学院废墟”或“官方中文”。

不包含原始数据库、网页/API完整快照、本机绝对路径、账号或运行资料、游戏候选、字体、签名私钥。不会为证明几条译文而附带整库。

## 来源与审查状态

`verification_level` 沿用原有四类：完整对应、部分/概念依据、未找到可靠全文、明确原样保留。`ai_expression_remaining` 标明是否仍有AI表达。

来源标注MTGZH/MTGso的内容保持社区来源；被标为未采用的来源不会因出现在索引中变成译文依据。完整对应的社区文本不代表官方译文。现有记录经过独立AI审查，未因此变成人工审定或真实游戏验收。

此目录不是安装批准，也不替代原有维护准入。其他机器可以复用文本和匹配信息，但采用前仍需核对当前游戏英文、用途、身份与格式，按现有流程完成必要来源复核、候选检查和游戏验收。

## 检查和更新

使用Python 3.11及现有维护器依赖：

```sh
python3 tools/chinese-maintainer/maintenance_data.py validate maintenance-data/2026.64.50
```

维护者从已完成原始来源检查、具有独立审查的V2包导出；导出先在本地校验原证据，不把它们复制进公开数据：

```sh
python3 tools/chinese-maintainer/maintenance_data.py export \
  --pack /本地已审查批次一/pack.json \
  --pack /本地已审查批次二/pack.json \
  --output /一个全新的导出目录
```

导出不能覆盖既有目录；重复层/Key、审查指纹不符、格式变化或私人路径会失败。原始包、来源数据库及原始快照保持原样，不改写历史证据。

第三方文字与社区译文保留来源归属，不因源码MIT许可证而被重新授权。公开数据的范围见根目录 `THIRD_PARTY_NOTICES.md`。
