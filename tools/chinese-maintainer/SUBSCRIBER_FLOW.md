# MTGA 汉化使用说明

按顺序完成：准备游戏 → 安装工具 → 下载并检查 → 安装或更新汉化。以后更新直接使用桌面入口。

## 安装前

- 支持 macOS 13 或以上的 Steam 版 MTGA。目前适配 M 系列 Mac；具体游戏版本见[项目首页](../../README.md)。
- 等 Steam 更新完成，打开游戏完成游戏内下载。
- **在游戏设置里把语言选为 English（英语），以后也要保持 English。** 汉化使用英语文本位置，选择其他语言可能看不到汉化。
- 完全退出 MTGA。安装和撤销更新期间，不要启动游戏，也不要让 Steam 验证或更新游戏文件。

## 第一次安装

1. 从[项目首页](../../README.md)下载更新工具，解压 ZIP。
2. 双击「安装 MTGA 中文维护.command」，等出现“安装完成”。桌面同名入口会自动替换。macOS 放行的图文步骤直接见[项目首页](../../README.md)。
3. 双击桌面的「MTGA 订阅更新.command」。如果没有桌面入口，使用安装完成时显示的备用路径。
4. 输入 **2 检查更新**，确认有适合当前游戏的汉化。
5. 输入 **3 下载并检查**。等待完成提示，这一步不修改游戏。
6. 确认游戏已完全退出，输入 **4 安装或更新汉化**。工具先备份，再安装汉化。
7. 出现“更新已应用”后再启动游戏。语言仍保持 **English**，检查中文显示和牌表导入。

输入菜单数字后按回车。每次操作结束后按回车返回菜单；输入 **0** 退出工具。

## 下载的文件能删吗？

**普通联网安装包：看到“安装完成”后，ZIP 和解压出的安装包文件夹都可以删除。** 工具已经装到本机，以后打开桌面入口即可，不需要保留下载目录。

不要删除桌面入口，也不要手动清理 `~/Library/Application Support/MTGAChineseSubscriber`：其中存有工具、下载缓存、备份和恢复记录。这里的 `~` 表示你的用户文件夹。

只有明确写着“离线演示包”的开发测试包必须保留解压目录；它不是首页提供的普通联网安装包。

## 每次更新

1. 如果 Steam 或游戏有更新，先完成全部下载，确认游戏语言仍为 **English**，再完全退出 MTGA。
2. 打开桌面工具，依次选 **2 检查更新 → 3 下载并检查 → 4 安装或更新汉化**。
3. 更新成功后再启动游戏。

普通汉化内容修正不需要重装工具。只有工具明确提示需要升级维护工具时，才从项目首页重新下载安装包。下载中断可重新选 **3**，已完成且检查通过的文件会复用；不要手动复制发布页里的其他附件到游戏目录。

工具不会在后台自动更新游戏。收到邮件只是提醒，仍需自己打开桌面工具操作。

## 菜单怎么选

| 数字 | 名称 | 作用 |
| --- | --- | --- |
| 1 | 查看当前汉化 | 查看安装记录，并检查已安装文件 |
| 2 | 检查更新 | 查询是否有适合当前游戏的汉化，不安装 |
| 3 | 下载并检查 | 准备和检查文件，不修改游戏 |
| 4 | 安装或更新汉化 | 自动备份当前文件，再安装汉化 |
| 5 | 撤销上次更新 | 还原上次应用之前的文件，也可处理安装中断 |
| 6 | 使用说明 | 查看本说明的操作要点 |
| 0 | 退出 | 关闭菜单 |

## 出问题怎么办

- **没有适配版本：** 等待维护者发布，不要强行安装其他游戏版本的汉化。
- **下载失败：** 检查网络，重新选 **3**。检查完成前不会开始替换游戏文件。
- **更新后有问题或安装中断：** 完全退出游戏，选 **5 撤销上次更新**。恢复的是更新前实际文件，不一定是官方原版；原来用了其他汉化，就恢复到那份汉化。
- **提示无法恢复或文件校验失败：** 停止重复操作，保留完整提示并到项目反馈。Steam 已升级游戏时，不能用旧版本备份强行覆盖。

## 收到更新邮件

登录 GitHub，在仓库选择 **Watch → Custom → Releases → Apply**，并开启 GitHub 邮件通知。Star 只表示支持，不会自动订阅邮件；不订阅也能主动检查更新。
