# 私有云端交付候选

模式：实现及私有验证，不公开发布、不设置定时、不更改已试装的 r3 游戏文件。

目标：已授权普通 Chat 可以重复请求云端候选；本机可以通过现有 GitHub 登录拉取私有数据包，核对构建来源、整包摘要及精确文件清单，再由现有原生维护工具预演、安装和恢复。

## 本轮边界

- 源码仍在私有 maintainer 仓库，云端执行及数据包仍在私有 probe 仓库。
- 旧 r3、本机原公开信任及原有桌面恢复入口保留。本轮用独立桌面验证入口。
- 云端只能生成候选与报告，不触发 Mac，不执行游戏，不发布公开订阅。
- 更新公告是触发信号，不代表已经找到当前 macOS 资源指针。
- 未适配的 build/generation/未知输入必须返回需要适配；不能把已知固定 r3 的成功当成所有未来版本自动适配。
- 不读取或导出 GitHub Token，不使用 Steam 密码，不重新授权 Steam。
- 不修改 TLS、隔离属性、Gatekeeper 或系统权限。

## 私有接收依赖

本轮原型复用本机已安装的 Python 3 标准库及 GitHub CLI 2.98.0。没有新增第三方 Python 包，不打包或分发 gh。新 CLI 路径与摘要由本机安装配置绑定；网络数据不能选择可执行程序。

gh 上游为 GitHub CLI，准确版本 v2.98.0，MIT：
https://raw.githubusercontent.com/cli/cli/v2.98.0/LICENSE

传输仅调用指定私有仓库的 GET API。凭据留在 gh 自身的已登录账户中；子进程移除环境 Token 和调试开关，不输出认证日志。删除新增桌面入口及本轮独立接收目录即可移除候选接收器，原 native 工具继续可用。

## 验证要求

1. 下载前校验私有仓库、指定 producer workflow/ref/完整源码身份及成功运行。
2. 制品 ID、producer run/head、大小与服务端摘要必须匹配，再对整包重算 SHA-256。
3. ZIP 必须是精确的有限文件清单；禁止路径穿越、符号链接、可执行成员、未知文件和过度解压。
4. 数据包不携带程序，只携带原生协议的数据、签名和补丁。
5. 原生工具的签名、资源白名单、版本、游戏退出、备份与恢复校验保持生效。
6. 实际私有下载、原生预演和隔离安装恢复分别留证；测试替身不代表真实权限或游戏验收。
7. 可重复运行和 NO_CHANGE 必须实跑；新调度目前不启用。

用户可见完成条件：独立桌面入口可以检查私有云端候选、验证完整下载并完成真实原生预演；隔离安装/恢复通过；原 r3 和恢复入口不变。

## 桌面入口及恢复边界

新增入口名称为 `MTGA 云端私有更新.command`。菜单提供查看状态、拉取并检查、预演、手动应用和恢复。没有后台安装或新定时任务。

安装目录独立于已试装的 r3。启动前核验 Python、三份接收端源码和本机配置；接收器再核验已有 native 与 gh。接收器既不读取也不输出登录令牌。操作 `status` 与 `rollback` 使用本地记录，不依赖 GitHub 凭据或网络。

检查只保存候选选择。应用之前先原子保存待处理记录，原生安装确认成功后才更新已安装记录。中断时禁止开始下一次安装；缺少安装日志、未知文件变化或版本改变都会停止。相同候选五层内容重新签名或重新打包，不会替换原先真正更新前的备份和恢复指针。

当前原型仅覆盖固定 `2026.64.0 / 25763111 / localization-b232…-client-933…`。状态页只作为更新信号。未来游戏版本、资源世代的自动定位尚未完成；官方输入仍依赖有限期的私有云端制品，过期必须停止并补充来源。不能把这轮固定目标的重复构建、NO_CHANGE 或桌面预演视为未来版本自动汉化成功。

## 大包接收修正

实际私有数据包为 145,094,076 字节。单连接接收在本机明显降速，因此增加大包分段续传：每块 4 MiB，最多四个已有 gh 子进程，仅向同一 artifact GET 端点添加数字 Range 头。每块最多等待 300 秒、最多三次尝试。子进程限制写入大小，错误输出不转发。

完成块保留在权限为 0700 的独立暂存目录，元数据绑定 artifact ID、完整包摘要/大小及块长。它们在整包 SHA-256 通过前始终是不可信缓存；不能据此解包、验签或应用。服务端忽略 Range、大小不符、未知文件、符号链接或元数据不符均停止；整包摘要失败清除所有块。中断杀掉并回收活跃下载进程、清理未完成块，下一次检查可复用已完成块。

28 项本机回归包含真实下载替身子进程：续传重试、服务端忽略 Range、缓存块投毒、元数据/文件集合拒绝，以及中断时四个下载进程退出后再次成功续传。未放宽整包摘要、精确 ZIP 清单、源码身份或原生签名要求。
