# 订阅客户端资源刷新修复候选

模式：实现与独立审查，仅私有候选；不发布、不安装、不修改游戏。

目标：同一 MTGA/Steam 版本发生资源世代变化时，检查更新应给出准确中文状态并停止不匹配安装；预演和应用继续验证签名、活动路径及五层指纹。安装入口应清晰可找到，不误报桌面入口已建立。消除重复执行不同路径下未公证二进制的交付设计问题，但没有 Developer ID 时不声称已通过 Apple 验证。

背景：用户实际文件已变为 Raw_ClientLocalization_933dea180457bbc4b007289db311dd9b.mtga，原 r2 引用 ff2c 文件已不在活动目录；主版本仍2026.64.0，Steam build25763111。只读诊断采集了公开 manifest 文件标识及必要文件列表，未上传游戏数据或 Player.log。官方新清单和 payload 后续由云端重新下载。

允许：tools/subscriber 的最小实现、相关回归测试、打包及私有 GitHub Actions。源码从已提交本地工作树恢复到私有云端，来源清单见 source-recovery-20261017.json；不导入本机状态、缓存、事务、密钥、游戏资源或历史日志。所有编译与测试在云端进行。

约束：不删除或改名游戏资源，不把旧译文库写到新文件名，不放宽路径/签名/过期/回退守卫；无强制覆盖、无移除 quarantine 或关闭 Gatekeeper。现有生产分支、签名索引、已发布包和安装状态均保持原样。没有会员/Developer ID，不借用证书或发起付费开通。

验收：云端原生 Swift 回归覆盖旧 signed release 缺文件但活动新资源存在、同版本新 revision、多个/缺失/符号链接资源、未知指纹、回退及恢复；完整原有针对性网络/缓存/事务测试。打包检查入口位置和重复安装；不把 Linux/fixture/构建成功当作真实 Gatekeeper 或游戏验收。新适配数据候选由独立 probe 分支处理，不与程序发布混为一谈。

风险与未知：本轮无 Developer ID/公证条件，首次下载运行提示不能承诺消除；Finder 显示与真实干净下载 UX 需要独立真实验收；当前资源世代的迁移/显示未验证。任何发布均留待具体候选审查后决定。
